abstract: >-
  An open-source Python library and CLI that defines each language's lexical rules once and runs shared
  analyses on the token stream, supporting 187 languages. Comment and string classification reach F1 of
  0.994 and 0.958 on 1,412 files in 12 languages, running 3x faster than assembled per-language tools.
