abstract: >-
  Analyzes 338 pull requests from 255 GitHub repositories with self-admitted ChatGPT usage, comprising
  645 AI-generated snippets and 3,486 developer-authored patches. Full adoption of AI-generated code is
  infrequent (median integration rate of 25%); developers rely on selective extraction and iterative refinement.
