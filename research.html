Research

I study how software evolves, how defects propagate through codebases and ecosystems, and how AI is changing the way software is built, through large-scale repository mining, program analysis, and empirical methods. My work is grounded in two broad areas: Empirical Software Engineering and AI for Software Engineering. I work in the Software Evolution (EVOL) Lab at UNLV, advised by Prof. John Businge.

Patch Integration in Software Variants

When a bug is fixed in one fork of a software project, that fix rarely makes it automatically into related forks, even when they share the same vulnerable code. The problem worsens over time as forks diverge through independent refactoring: renamed methods, moved classes, and restructured hierarchies cause patch replay to fail silently, leaving users of downstream variants exposed to known bugs.

My work in this area asks: how do patches propagate across structurally divergent variants, and how can we make that propagation reliable and automated? I build tools and datasets that make patch integration refactoring-aware, and study AI-generated patch adoption at scale across real GitHub fork networks.

Code Smells & Software Quality

Design smells (structural anti-patterns like God Classes, Long Methods, and Feature Envy) accumulate quietly as software grows, increasing maintenance cost and bug density long before they trigger visible failures. Understanding where smells appear, why they persist, and what role they play in software evolution is essential to building practical detection and remediation tools.

My work examines how design smells manifest and evolve across desktop and mobile platforms, characterizes the structural roles smells play during software change, and produces reusable benchmark datasets that enable reproducible smell detection research.

AI Coding Agents & LLMs for Software Engineering

AI coding agents are systems like GitHub Copilot, Devin, and Cursor that autonomously write, test, and submit code, moving from assistants to active contributors in real codebases. Yet we have little empirical understanding of how their contributions differ from human work, what failure modes emerge when multiple agents collaborate, or how developers actually integrate AI-generated code into production.

My research characterizes agent-generated pull requests at scale, covering commit patterns, code change semantics, and merge conflict rates, and studies the new class of coordination problems that arise when autonomous agents concurrently modify shared repositories.

Software Ecosystems & Data Infrastructure

No package exists in isolation. Library updates ripple through dependency graphs, security vulnerabilities propagate across ecosystems, and the health of a single widely-used artifact can affect thousands of downstream projects. Understanding these ecosystem-level dynamics requires treating software not as individual repositories but as interconnected networks.

I apply graph mining and repository analysis to map how package ecosystems evolve structurally over time. Separately, I contribute to the AirQo project, where the focus is on building and evaluating reliable data pipelines for large-scale environmental monitoring across Africa.
