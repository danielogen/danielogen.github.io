    <h5 class="mt-2 mb-1">PatchTrack: ChatGPT's Influence on Pull Request Outcomes</h5>
    <p class="small text-muted mb-2">Daniel Ogenrwot &middot; John Businge</p>
    <p class="small mb-3">
        Studying <strong>338 pull requests</strong> from 255 GitHub repositories with self-admitted
        ChatGPT usage, PatchTrack finds that full adoption of AI-generated code is infrequent, with a
        median integration rate of <strong>25%</strong>. Developers use selective extraction and iterative
        refinement rather than direct acceptance, showing AI's influence extends beyond patch generation
        to the entire code review process.
    </p>
