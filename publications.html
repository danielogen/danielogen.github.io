PyReprism: A Shared Lexical Foundation for Polyglot Code Analysis

Daniel Ogenrwot, Jorge Gonzalo Delgado Cervantes, Richard Sserunjogi, John Businge
arXiv preprint arXiv:2610.39224, 2026

An open-source Python library and CLI that defines each language's lexical rules once and runs shared analyses on the token stream, supporting 187 languages. Comment and string classification reach F1 of 0.994 and 0.958 on 1,412 files in 12 languages, running 3x faster than assembled per-language tools.

EMSE 2026Journal

PatchTrack: A Comprehensive Analysis of ChatGPT's Influence on Pull Request Outcomes

Daniel Ogenrwot, John Businge
Empirical Software Engineering (EMSE), 31(5), 136, 2026 19 citations

Analyzes 338 pull requests from 255 GitHub repositories with self-admitted ChatGPT usage, comprising 645 AI-generated snippets and 3,486 developer-authored patches. Full adoption of AI-generated code is infrequent (median integration rate of 25%); developers rely on selective extraction and iterative refinement.

MSR 2026Conference

How AI Coding Agents Modify Code: A Large-Scale Study of GitHub Pull Requests

Daniel Ogenrwot, John Businge
23rd International Conference on Mining Software Repositories (MSR), Mining Challenge Track, 2026 19 citations

Large-scale empirical comparison of ~24,000 merged agentic pull requests against 5,000 human-authored PRs using the AIDev dataset, examining additions, deletions, commits, and files modified. Finds that AI-generated PRs show substantially higher commit counts and slightly superior description-to-code alignment across multiple similarity measures.
