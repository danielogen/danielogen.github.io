AgenticFlict

Merge conflicts in pull requests written by AI coding agents

AI coding agents such as Copilot, Devin, and Cursor now open pull requests in real repositories. When several of them touch the same code, their changes collide, but nobody had measured how often or how badly.

142K+
agentic pull requests
29K
PRs with merge conflicts
336K+
conflict regions extracted
  • Mined from 59K+ GitHub repositories, giving a large-scale view of agent-authored merge conflicts.
  • Conflicts in agentic PRs are both frequent and often substantial in size.
  • Released openly with the full curation pipeline for follow-up research.

PatchTrack

How developers actually use ChatGPT-generated code in pull requests

Developers increasingly paste ChatGPT suggestions into their pull requests. Is that code merged as is, reworked, or thrown away, and what does it do to code review?

338
pull requests studied
255
GitHub repositories
25%
median integration rate
  • Full adoption of AI-generated code is rare; developers extract parts and refine them iteratively.
  • ChatGPT shapes the whole review conversation, not just the patch itself.
  • Extends the ASE 2024 poster into a full EMSE journal study.
Paper Preprint Code 19 citations
Patch Integration Across Forks SCAM 2025 Distinguished Artifact Award

RePatch

Refactoring-aware patch integration across divergent Java forks

A bug fixed in one fork rarely reaches its sibling forks. Once forks refactor independently, renamed methods and moved classes make cherry-picking fail, leaving users exposed to bugs that are already fixed elsewhere.

52.8%
failing patches recovered
Award
Distinguished Artifact, SCAM 2025
  • Detects structural drift between forks and inverts refactorings on both sides before replaying the patch.
  • Evaluated on a benchmark of real cross-fork patches that naive cherry-pick could not apply.
  • The tool and benchmark are open source and fully reproducible.
